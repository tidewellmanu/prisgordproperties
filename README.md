# Prisgord Properties — Static Codebase

Pure HTML5, CSS3 and vanilla JavaScript. No React, Next.js, Vue, Angular, npm or build step.

## Run
Use VS Code Live Server or:
`python3 -m http.server 8000`
Then open `http://localhost:8000/`.

## Production
Replace placeholder phone/email/domain. Replace demonstration property data/images with content Prisgord Properties is authorized to publish. Inspection and contact forms currently open the user's email client; connect them to a secure backend/form service for production. Keep secrets out of frontend code.

## Main pages
index.html, properties.html, property.html, properties-on-display.html, saved-properties.html, schedule-inspection.html, services.html, about.html, contact.html plus category and service pages.
